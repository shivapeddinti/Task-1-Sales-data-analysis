# Sales Data Analysis

## Project Overview
This project analyzes sales transactions to calculate important business metrics, compare product and category performance, examine monthly and quarterly trends, and visualize geographic sales distribution.

## Objectives
- Calculate gross revenue, discounts, net sales, product cost, profit, profit margin, Average Order Value (AOV), and units sold.
- Analyze monthly and quarterly sales trends.
- Identify top-selling products and categories.
- Identify products with the highest profit margins.
- Compare sales performance across regions and sales channels.
- Validate financial totals and generate business insights.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses `Sales_Data.csv` as the input dataset.

Keep the CSV file in the same folder as the Jupyter Notebook.

## How to Run

1. Install Python and Jupyter Notebook.
2. Install the required libraries:

   `pip install pandas numpy matplotlib seaborn jupyter`

3. Keep `Sales_Data.csv` and `Sales_Data_Analysis.ipynb` in the same folder.
4. Open `Sales_Data_Analysis.ipynb`.
5. Select **Kernel → Restart Kernel and Run All Cells**.
6. View the analysis results, tables, and visualizations.

## Outputs
- Key business metrics and financial reconciliation checks.
- Category-wise and product-wise sales and profit summaries.
- High-margin product ranking and chart.
- Monthly and quarterly sales trend charts.
- Calendar-month comparison and year-month trend.
- Regional and sales-channel comparisons.
- Business insights and strategic recommendations.

## Interpretation Notes
Profit margin and total profit are different measures. A product may have a high profit margin but contribute less total profit if its sales volume is low.

The available dataset covers less than two complete years. Therefore, calendar-month comparisons are exploratory and cannot establish a reliable recurring seasonal pattern.

## Business Recommendations
- Monitor stock levels and demand for top-selling products.
- Evaluate high-margin products for promotions and bundles without reducing profit margins.
- Investigate lower-performing regions and categories before reallocating marketing budgets.
- Compare profit as well as sales when evaluating sales channels.
- Collect more data before making strong seasonal or forecasting predictions.
